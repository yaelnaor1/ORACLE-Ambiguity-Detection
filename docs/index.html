Methodology

Experiments

Each experiment was run on all 391 queries, with results saved row-by-row for safe resumption.

1

Dataset Preparation

Downloaded 500 queries from the AmbigQA dataset via HuggingFace — 333 ambiguous and 167 unambiguous. Each query includes a gold clarifying question and gold answer for reference-based scoring.

AmbigQA HuggingFace 500 queries
2

Baseline Evaluation

Both GPT-4o and Claude were given each query with a simple instruction: answer directly or ask one clarifying question. No ambiguity detection mechanism — pure single-pass generation.

GPT-4o Claude Sonnet 4.6 Zero-shot
3

Debate-Lite Pipeline

Two models (GPT-4o and Claude) independently interpret each query. An analyst compares their interpretations to detect conflict, classifies the ambiguity type using AT-CoT taxonomy, and triggers a clarifying question if needed.

AT-CoT Taxonomy 4 API calls Semantic / Generalize / Specify
4

ORACLE Full Pipeline

Extends Debate-Lite with two additional quality-control agents: a Devil's Advocate that challenges the initial clarifying question, and an internal Judge that scores v1 vs v2 on three axes and picks the winner.

6 agents ~9 API calls Devil's Advocate Internal Judge
5

Method 1 — Gemini Judge (Qualitative)

Gemini 2.5 Flash acts as an independent evaluator, scoring each system's output on three axes (Relevance, Specificity, Necessity — 1 to 5 each) plus two binary flags (Hallucination, False Positive). Gemini was chosen to avoid self-preference bias since GPT-4o and Claude are both inside the pipeline.

Gemini 2.5 Flash Independent judge 5 metrics
6

Method 2 — Automatic Scoring

Three automatic metrics computed against gold references: ROUGE-L (word overlap), BERTScore (semantic similarity via RoBERTa), and ARR — a novel Ambiguity Resolution Rate metric that checks whether the clarification leads to the correct final answer.

ROUGE-L BERTScore ARR (novel metric)

Analysis

Key Findings

🎯

Baselines fail at ambiguity

GPT-4o hallucinates on 98.2% of ambiguous queries — answering confidently instead of asking. Claude does the same at 91%. Single-pass models cannot reliably detect ambiguity.

⚡

Multi-agent debate works

Debate-Lite drops hallucination from 98% to 7.4% with just 4 API calls. Two independent interpreters plus an analyst is enough to dramatically improve ambiguity detection.

🏆

ORACLE = highest precision

ORACLE achieves the lowest false positive rate (1.3%) — it almost never asks a clarifying question on a clear query. The Devil's Advocate + Judge pipeline provides this precision.

📉

ROUGE-L misleads here

Baselines score higher on ROUGE-L/BERTScore because their verbose answers accidentally overlap with reference text. This shows lexical overlap metrics are unreliable for this task.

✅

ARR is the right metric

ARR (Ambiguity Resolution Rate) correctly captures outcome quality — ORACLE (84.9%) and Debate-Lite (86.2%) both far outperform baselines (~61%) when measuring actual resolution.

⚖️

Precision vs. Recall tradeoff

ORACLE is conservative — it only detects 95 of 224 ambiguous queries (recall 27.7%) but is precise when it does (65.3%). More agents = higher quality but lower coverage.
